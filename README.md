## 📦 Installation

Since this extension contains a 1.6GB offline model, it is distributed as a pre-packaged `.vsix` file via GitHub Releases.

1. Go to the [Releases page](../../releases) of this repository.
2. Download the latest `spirita-x.x.x-spoofed.vsix` file.
3. Open Visual Studio Code.
4. Press `Cmd + Shift + P` (or `Ctrl + Shift + P`).
5. Type and select: **`Extensions: Install from VSIX...`**
6. Select the downloaded `.vsix` file.
7. Reload your VS Code window (`Cmd + Shift + P` -> `Developer: Reload Window`).
